## Pattern

Ground taste first: `learn-taste`, then MengTo's `no-ai-design-slop` /
`audit-ai-design-slop` guard against generic AI aesthetics; `apple-design`,
`break-ui`, `pick-ui-library`, `prototype` raise the bar; `emil-design-eng`
is the reference standard. Output surfaces: `canvas-design` and
`web-artifacts-builder` for graphics and interactive artifacts,
`theme-factory` for themes, `brand-guidelines` when a brand exists,
`algorithmic-art` for generative work. Web and UI builds combine these with
`frontend-design` and the layout/typography/color family, plus MengTo's
web-design recipes for concrete patterns (hero, pricing, landing, dashboards).
Inside UAP Console work the DESIGN.md token system is mandatory — the design
gate blocks off-token values. Finish with `critique`, `normalize`, `polish`;
never self-grade.
